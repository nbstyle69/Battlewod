AthleX

Politique de Confidentialité

Dernière mise à jour : 14 mars 2026

1. Introduction

AthleX (« nous », « notre ») est une application mobile de compétition functionnal fitness & hybrid. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons vos données personnelles.

2. Données collectées

Nous collectons les données suivantes :

  • Informations de compte : email, pseudo, mot de passe (chiffré), niveau athlète
  • Données de profil : photo de profil, bio, personal records (PR)
  • Données de performance : scores WOD, classement ELO, vidéos de performance
  • Données de compétition : participations tournois, matchs, résultats
  • Communications : messages envoyés dans les chats de box
  • Données techniques : type d'appareil, système d'exploitation, token de notification push

3. Utilisation des données

Vos données sont utilisées pour :

  • Fournir et améliorer les fonctionnalités de l'application
  • Gérer votre compte et votre profil athlète
  • Calculer et afficher les classements ELO
  • Permettre la participation aux compétitions et tournois
  • Envoyer des notifications push (si autorisées)
  • Permettre la communication au sein des boxs

4. Stockage et sécurité

Vos données sont stockées de manière sécurisée via Supabase, hébergé sur des serveurs conformes aux standards de sécurité modernes. Les mots de passe sont chiffrés et ne sont jamais stockés en clair. Les communications entre l'application et nos serveurs utilisent le protocole HTTPS.

5. Caméra et microphone

L'application peut demander l'accès à votre caméra et microphone pour enregistrer vos performances WOD. Ces enregistrements sont :

  • Stockés localement sur votre appareil
  • Partagés uniquement si vous choisissez de soumettre une vidéo
  • Jamais accessibles sans votre consentement explicite

6. Galerie photos

L'accès à votre galerie est utilisé uniquement pour :

  • Sauvegarder vos vidéos de performance
  • Choisir une photo de profil

7. Notifications push

Nous utilisons les notifications push pour vous informer des résultats de compétitions, rappels d'entraînement et activité de votre box. Vous pouvez les désactiver à tout moment dans les paramètres de l'application.

8. Partage des données

Nous ne vendons jamais vos données personnelles. Vos données peuvent être visibles par :

  • Les membres de votre box (pseudo, niveau, scores, classement)
  • Les participants d'une compétition (scores, vidéos soumises)
  • Le gérant de votre box (données de membres)

9. Vos droits

Conformément au RGPD et aux lois applicables, vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier vos informations via votre profil
  • Supprimer votre compte et toutes vos données
  • Exporter vos données sur demande
  • Retirer votre consentement aux notifications à tout moment

10. Conservation des données

Vos données sont conservées tant que votre compte est actif. En cas de suppression de compte, vos données personnelles sont effacées dans un délai de 30 jours.

11. Modifications

Cette politique peut être mise à jour. Nous vous informerons de tout changement significatif via l'application.

12. Contact

Pour toute question relative à vos données personnelles, contactez-nous à : contact@athlexapp.eu
